The way to use this website is pretty easy. All you gotta do is to learn it. 

New updates to the website:
Files
index.html - the page structure (header, About, Projects, Skills, Contact, footer).
styles.css - the layout, colours, hover effects, and CSS-only fallback slideshow.
script.js - all of the interactive features described below.
images/ - the photos used on the page.
Features
Hero slideshow

McLaren photos in the header change automatically every 4 seconds. Use the arrow buttons or the dots to switch photos manually. The slideshow pauses while the mouse is over it.

Project filters

Buttons above the project cards (All, Python, Raspberry Pi, HTML/CSS) show only the projects with that tag. Clicking a skill in the Skills section applies the same filter and scrolls to the projects. Skills with no projects yet (such as Git) show a short message instead.

Language switcher

Use the EN | ID buttons in the navigation bar to switch the whole page between English and Indonesian. On the first visit the language is chosen from the browser's settings, and the choice is remembered for the next visit. To add another language, copy the en block in the I18N object in script.js and translate the values.

Navigation highlight

The link of the section you are currently viewing is highlighted in the navigation bar.

Copy email

Clicking "Gmail" in the Contact section copies my email address to the clipboard instead of opening a mail app.

Back-to-top button

After scrolling down a little, a round arrow button appears in the bottom-right corner. Clicking it scrolls smoothly back to the top.

Scroll reveal

The About section, project cards, and skills fade in as they scroll into view.

Logo link

The "sir.s" logo in the navigation bar opens a YouTube video in a new tab.

How to use
Download or clone the project and keep all files in the same folder structure.
Open index.html in any modern web browser. No installation or build step is needed.
Scroll through the page or use the navigation bar to jump to a section.
Built with

HTML, CSS, and vanilla JavaScript (no libraries or frameworks).
